## 摘要
视觉-语言-动作（VLA）策略在通用机器人操作中展现出强大潜力，但在长时程执行过程中仍可能不可预测地失败，因此可靠的失败检测对于安全部署至关重要。现有方法要么依赖视觉模型，这些模型通常只在错误动作已经发生后才检测到失败；要么使用基于 VLA 内部表示训练的轻量级主动检测器。然而，这些主动方法通常使用轨迹级标签进行监督，导致不成功轨迹中失败前的正常行为被错误地标记为失败。这种监督不匹配引入了标签噪声，并限制了轨迹级检测准确率和精确的时间戳级失败定位。在本工作中，我们研究细粒度时间戳级 VLA 失败检测，同时解决密集标注的成本问题。我们提出一个数据高效框架，首先利用未标注的 VLA 动作块构建由动作导出的弱监督信号，捕捉诸如连续动作块不一致、动作冻结或空闲以及剧烈随机运动等异常模式。然后，我们使用主动学习仅选择最具不确定性的轨迹进行时间戳级标注，并利用这些信息量大的标签微调检测器。在多种 VLA 策略上的实验表明，我们的方法同时提升了时间戳级和轨迹级失败检测性能。

## Abstract
Vision-language-action (VLA) policies have shown strong potential for general-purpose robotic manipulation, but they can still fail unpredictably during long-horizon execution, making reliable failure detection essential for safe deployment. Existing methods either rely on visual models that typically detect failures only after erroneous actions have occurred, or use lightweight proactive detectors trained on VLA internal representations. However, these proactive methods are often supervised with trajectory-level labels, causing normal pre-failure behavior in unsuccessful trajectories to be incorrectly labeled as failure. This supervision mismatch introduces label noise and limits both trajectory-level detection accuracy and precise timestamp-level failure localization. In this work, we study fine-grained timestamp-level VLA failure detection while addressing the cost of dense annotation. We propose a data-efficient framework that first leverages unlabeled VLA action chunks to construct action-derived weak supervision signals, capturing abnormal patterns such as inconsistent consecutive chunks, frozen or idle actions, and aggressive random motions. We then use active learning to select only the most uncertain trajectories for timestamp-level annotation and fine-tune the detector with these informative labels. Experiments across multiple VLA policies show that our method improves both timestamp-level and trajectory-level failure detection performance.

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）策略在通用机器人操作中表现突出，但在长时程执行中仍会不可预测地失败，例如错过目标、卡住、空闲或产生不稳定动作。可靠失败检测对安全部署、及时干预和恢复至关重要。
- **现有方法的两类局限**：
  - **反应式方法**：依赖执行后的视觉观测，通常要等错误动作已经发生并产生可见后果后才能检测失败，难以提前预警，且大模型逐步查询计算昂贵。
  - **主动式方法**：基于 VLA 内部表示或动作块训练轻量检测器，可在动作执行前输出失败分数，但常使用**轨迹级标签**监督**时间戳级检测**。
- **核心矛盾**：轨迹级标签会把失败轨迹中的所有时间戳都标为失败，包括失败发生前机器人仍正常执行的阶段。这造成监督错配和标签噪声，削弱正常/失败边界，既影响轨迹级检测，也阻碍精确的失败起始时间定位。
- **论文目标**：研究**细粒度时间戳级 VLA 失败检测**，在降低密集人工标注成本的同时，提高失败起始定位和整体检测性能。

## 2. 方法论

### 2.1 核心思想

FailureSpot 是一个**标签高效的两阶段框架**：

1. **弱监督预训练**：利用无标注 VLA 动作块构造动作导出的时间戳级软伪标签，无需人工时间戳标注。
2. **主动学习微调**：用预训练检测器估计不确定性，只挑选最有信息量的轨迹进行时间戳级人工标注，再微调检测器。

检测器输入为 VLA 内部表示 \(h_{i,t}\)，输出时间戳级失败概率 \(p_{i,t}=f_\theta(h_{i,t})\)，论文探索 MLP 和 LSTM 两种轻量检测器。

### 2.2 时间戳级失败标注定义

- 每个时间戳二分类：\(y_{i,t}=1\) 为失败，\(y_{i,t}=0\) 为正常。
- 失败定义为机器人不再向任务目标取得有意义进展，例如错过目标、卡住、空闲、随机运动或动作与任务不一致。
- 对失败轨迹，失败起始时间 \(t_{\text{dev}}\) 为第一个被标为失败的时间戳。
- 若轨迹曾偏离但后来恢复并成功，则只将 \(t_{\text{dev}}\le t<t_{\text{rec}}\) 标为失败；完全正常轨迹全标 0。

### 2.3 动作导出弱监督信号

论文从 VLA 输出动作块中提取三类异常信号：

- **短期动作一致性** \(c_{i,t}\)：
  - 连续动作块存在重叠时，计算前一块未执行动作与当前块执行动作之间的平均 \(\ell_2\) 距离。
  - 公式：\(c_{i,t}=\frac{1}{M}\sum_{j=1,\dots,M}\|a^{K+j}_{i,t-1}-a^j_{i,t}\|_2\)，其中 \(M=\min(K,H-K)\)。
  - 对 OpenVLA 等自回归策略，无重叠，则定义为连续动作距离 \(c_{i,t}=\|a_{i,t-1}-a_{i,t}\|_2\)。
  - 一致性越差，越可能失败或不稳定。
- **全动作块幅度** \(r_{i,t}\)：整个输出动作块的平均 \(\ell_2\) 范数。
- **执行动作幅度** \(r^{\text{exec}}_{i,t}\)：实际执行的前 \(K\) 个动作的平均 \(\ell_2\) 范数。
  - 幅度过小可能表示冻结/空闲；幅度过大或不稳定可能表示激进随机运动。
- **指数移动平均 EMA**：对每个信号计算 \(E^{(u)}_{i,t}=\beta E^{(u)}_{i,t-1}+(1-\beta)u_{i,t}\)，\(\beta=0.8\)，用于捕捉趋势并降噪。
- **组合信号**：
  \[
  s_{i,t}=(c_{i,t}+E^{(c)}_{i,t})+\eta_1(r_{i,t}+E^{(r)}_{i,t})+\eta_2(r^{\text{exec}}_{i,t}+E^{(r^{\text{exec}})}_{i,t})
  \]
  其中 \(\eta_1,\eta_2\) 为平衡超参。
- **归一化**：用训练集 1% 和 99% 分位数 \(s_{\text{low}},s_{\text{high}}\) 线性缩放并裁剪到 \([0,1]\)，得到软伪标签 \(\tilde{s}_{i,t}\)，用于预训练。

### 2.4 主动学习微调

- 用预训练检测器计算每个时间戳失败概率的熵：
  \[
  H(p_{i,t})=-p_{i,t}\log p_{i,t}-(1-p_{i,t})\log(1-p_{i,t})
  \]
- 轨迹不确定性为所有时间戳平均熵：
  \[
  U_i=\frac{1}{T_i}\sum_{t=1}^{T_i}H(p_{i,t})
  \]
- 按 \(U_i\) 排序，只对最不确定的轨迹请求时间戳级标注。
- 用这些标注以监督二分类损失微调检测器，从而结合弱监督的可扩展性与人工标注的准确性。
