## 摘要
自然语言指令的变化会直接改变机器人行为。可靠的具身系统应在任务不变时保持其动作，并在任务本身发生变化时正确更新动作。我们提出 One Word, Different Action，一个基于物理决策状态和可执行动作构建的真实机器人基准，利用任务保持和任务改变指令对，共同评估决策不变性与决策敏感性，并在多约束推理和真实 RGB grounding 条件下进一步评估。实验表明，现代模型在单约束指令变化上接近饱和，然而当多个任务约束必须整合为一个可执行决策时，若干模型会出现明显退化。这些结果表明，更突出的剩余挑战已不再是识别孤立的指令变化，而是将多个任务要求可靠地组合为正确的机器人动作决策。

## Abstract
Natural-language instruction changes can directly alter robot behavior. A reliable embodied system should preserve its action when the task is unchanged and update it correctly when the task itself changes. We introduce One Word, Different Action, a real-robot benchmark built on physical decision states and executable actions, using task-preserving and task-changing instruction pairs to jointly evaluate Decision Invariance and Decision Sensitivity, with further evaluation under multi-constraint reasoning and real-RGB grounding. Experiments show that modern models are near saturation on single-constraint instruction changes, yet several models degrade noticeably when multiple task constraints must be integrated into one executable decision. These results suggest that the more salient remaining challenge is no longer recognizing an isolated instruction change, but reliably composing multiple task requirements into a correct robot action decision.

# 论文总结：One Word, Different Action

## 1. 核心问题与整体含义
- **研究动机**：自然语言指令的细微变化会直接改变机器人行为。可靠的具身系统应区分两类变化：
  - 任务未变、仅语言表达变化：机器人应保持动作决策不变。
  - 任务本身改变：机器人应正确更新动作决策。
- **核心问题**：现有评测多关注最终任务成功率或孤立指令理解，缺少在**同一物理决策状态**下，控制指令变化并判断“动作应保持还是应更新”的诊断框架。
- **整体含义**：论文提出真实机器人基准 **One Word, Different Action**，把语言条件具身推理形式化为“指令变化 → 可执行动作决策是否应改变”的问题，并联合评估 **Decision Invariance（决策不变性）** 与 **Decision Sensitivity（决策敏感性）**。

## 2. 方法论
- **核心思想**：
  - 固定物理决策状态 \(s\) 与可执行动作空间 \(\mathcal{A}(s)\)。
  - 给定指令 \(x\)，模型输出动作决策 \(\pi(x,s)\)。
  - 正确决策 \(a^*(x,s)\) 由物理状态和任务约束确定性决定，自然语言仅用于表达约束。
- **两类指令变换**：
  - 任务保持 \(x^+\)：\(a^*(x,s)=a^*(x^+,s)\)，模型应保持动作 → 评估 **Decision Invariance**。
  - 任务改变 \(x^-\)：\(a^*(x,s)\neq a^*(x^-,s)\)，模型应更新动作 → 评估 **Decision Sensitivity**。
- **失败模式**：
  - **Over-Invariance**：任务已变但模型仍保持旧动作。
  - **Over-Sensitivity**：任务未变但模型错误改变动作。
- **任务类型**：
  - 单约束推理：动作抑制、集合约束、基数约束、时序约束。
  - 多约束推理：指令包含多个约束 \(C(x)=\{C_1,\dots,C_K\}\)，最终动作需同时满足所有约束。
- **基准构造流程**：
  - 先定义真实物理决策锚点、候选对象/动作与确定性任务约束。
  - 再确定唯一正确动作决策，最后生成自然语言指令。
  - 构造任务保持对与任务改变对，形成配对反事实测试。
- **输出与验证**：
  - 输出映射到有限、机器可检查的可执行动作表示。
  - 单动作需精确匹配；集合需完全一致；序列需成员与顺序均匹配。
